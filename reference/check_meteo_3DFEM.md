# Check meteo data input as required by the 3DCMCCFEM model

`check_meteo_3DFEM` perform some basic test on the variables in the
input meteo file (e.g., generated by the function `make_meteo_EOBS`) to
ensure compatibility with `run_3DCMCCFEM`. The function can also try to
correct inconsistency

## Usage

``` r
check_meteo_3DFEM(
  file_meteo,
  correct = TRUE,
  impute = TRUE,
  save = FALSE,
  plot = FALSE,
  ...
)
```

## Arguments

- file_meteo:

  Character or data.frame: path to meteo.txt file or data.frame of
  meteo.txt file read with read.table.

- correct:

  Logical: correct any errors found? Default to TRUE.

- impute:

  Logical: impute missing value using tree-based algorithm (bagging,
  requires the packages caret and ipred)? Default to TRUE.

- save:

  Logical: save meteo file?. Only if file_meteo is a path to a file. If
  TRUE, meteo file is saved with the same name and same directory of
  file_meteo. Default to FALSE

- plot:

  Logical: plot meteo file with `plot_meteo_3DFEM`?. Default to FALSE.

- ...:

  additional argument passed to `plot_meteo_3DFEM` when `plot=TRUE`

## Value

a data.frame with the corrected weather time series if `correct=TRUE`,
invisible otherwise. If `plot=TRUE` the function return a ggplot object
if `save_plot=FALSE`. If `save_plot=TRUE` the function save in `outdir`
a png file with the name of the site in `meteo_path_file`

## Details

The function check for consistency with the columns name convention of
the model, for NA, missing data, missing observation in the weather time
series, anomalous values in precipitation and temperature relations
(i.e., Tmin\<=Tmean\<=Tmax). If `correct=TRUE` colnames and temperature
are fixed according to model specifications. After all checks, if
`plot=TRUE` the function `plot_meteo_3DFEM` is call.
