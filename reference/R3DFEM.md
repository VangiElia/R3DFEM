# R3DFEM: an R package for running the 3D-CMCC-FEM model (version 5.7)

The R3DFEM package provides functions to install the model, create and
check the inputs of the simulations, run single simulations or batches
of simulations of the 3D-CMCC-FEM (version 5.7), read and plot inputs
and outputs. See
[`vignette("R3DFEM")`](https://vangielia.github.io/R3DFEM/articles/R3DFEM.md)
and
[`vignette("input-files")`](https://vangielia.github.io/R3DFEM/articles/input-files.md)
for an overview of the package functionality.

## Note

See the [official web
page](https://www.forest-modelling-lab.com/the-3d-cmcc-model) for a
complete documentation of the model.
