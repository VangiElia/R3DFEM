# Plot soil data input as required by the 3DCMCCFEM model

`plot_soil_3DFEM` plot the textural information of a soil.txt file
(e.g., generated by the function `make_soil_ISRIC`) required by the
model. Textural information is represented as the textural triangle with
the USDA system.

## Usage

``` r
plot_soil_3DFEM(
  soil_file_path = NULL,
  save_plot = FALSE,
  outdir = NULL,
  main = "",
  show.names = TRUE,
  show.lines = TRUE,
  col.names = "gray",
  bg.names = par("bg"),
  show.grid = FALSE,
  col.axis = "black",
  col.lines = "gray",
  col.grid = "gray",
  lty.grid = 3,
  show.legend = FALSE,
  label.points = FALSE,
  point.labels = NULL,
  col.symbols = "red",
  pch = par("pch"),
  ...
)
```

## Arguments

- soil_file_path:

  Character vector: vector of paths to soil.txt input files.

- save_plot:

  Logical: Should plots be saved in outdir? Default to FALSE.

- outdir:

  Character: path to the output directory.

- main:

  Character: title of the plot.

- show.names, show.lines:

  Logical: show the names of the USDA texture classes and the lines
  between them? Default to TRUE.

- col.names, bg.names:

  Colors of the names of the texture classes and of their background.

- show.grid, col.grid, lty.grid:

  Show a grid, and its color and line type.

- col.axis, col.lines:

  Colors of the axes and of the class lines.

- show.legend, label.points, point.labels, col.symbols, pch:

  Arguments passed to
  [`plotrix::triax.points`](https://plotrix.github.io/plotrix/reference/triax.points.html).

- ...:

  Other arguments passed to
  [`plotrix::triax.points`](https://plotrix.github.io/plotrix/reference/triax.points.html).

## Value

Invisible. The function is called for its side effects. If
`save_plot=TRUE` the function save in `outdir` a png file with the name
of the site in `soil_file_path`

## Details

The function plots the textural characteristics of soil from the input
soil.txt file required by the 3D-CMCC-FEM model. Based on the `plotrix`
package. See plotrix::triax.plot for all possible arguments.
