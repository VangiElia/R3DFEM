# Plot meteo data input as required by the 3DCMCCFEM model

`plot_meteo_3DFEM` plot the variables in the input meteo file (e.g.,
generated by the function `make_meteo_EOBS`) required by the model.

## Usage

``` r
plot_meteo_3DFEM(
  meteo_file_path = NULL,
  var = "all",
  daterange = c("1980-01-01", "2022-06-30"),
  window = NULL,
  save_plot = FALSE,
  outdir = NULL
)
```

## Arguments

- meteo_file_path:

  Character: path to simulation output file.

- var:

  Character vector: vector of variables name to be plotted. Default to
  "all" to plot all variables.

- daterange:

  Character vector of length 2: starting and ending date from which to
  plot meteo data. Must be in the form yyyy-mm-dd. Default to the time
  range of the EOBS dataset

- window:

  Numeric: dimension of the focal window for compute the rolling mean.
  Expressed in days. Default to NULL (rolling mean is not plotted).

- save_plot:

  Logical: Should plots be saved in outdir? Default to FALSE.

- outdir:

  Character: path to the output directory.

## Value

A ggplot object if `save_plot=FALSE`, invisible otherwise. If
`save_plot=TRUE` the function save in `outdir` a png file with the name
of the site in `meteo_path_file`

## Details

The function plots the time series of the specified variables, as
reported from `make_meteo_EOBS`. It tries to guess the best time scale
for the x-axis based on the `daterange` argument. The `window` argument
should be appropriate to the desired time frame.
