# Plot the annual output of the 3DCMCCFEM model

`plot_output_3DFEM` plot the variables in the output file of the model
(e.g., generated by the function `run_3DCMCCFEM`).

## Usage

``` r
plot_output_3DFEM(
  output_3DFEM,
  x = NULL,
  y = NULL,
  site_name = NULL,
  year_range = NULL,
  window = NULL,
  text_size = 40,
  save_plot = FALSE,
  outdir = NULL
)
```

## Arguments

- output_3DFEM:

  Character: path to the model output file.

- x:

  Character vector of length 1: variable name to be plotted in the
  x-axis. If not provided will be set to the variable "YEAR"

- y:

  Character vector: variable name to be plotted in the y-axis. Could be
  of length \>1 if x is NULL. In this case variables will be plotted on
  different facets

- site_name:

  character vector of length 1: site name to be plotted as title.
  Optional

- year_range:

  numeric vector of length 2: starting and ending year from which to
  plot the data. It will be sorted in ascending order

- window:

  Numeric: dimension of the focal window for compute the rolling mean.
  Expressed in years Default to NULL (rolling mean is not plotted).

- text_size:

  Numeric: base size of the text in the plot. Default to 40.

- save_plot:

  Logical: Should plots be saved in outdir? Default to FALSE.

- outdir:

  Character: path to the output directory.

## Value

A ggplot object if `save_plot=FALSE`, invisible otherwise. If
`save_plot=TRUE` the function save in `outdir` a png file. The file name
will be constructed based on the argument provided (x, y, site_name,
year_range, and window)

## Details

The function plots the time series of the variables specified by y. The
`window` argument should be appropriate to the desired time frame. If x
is provided, a scatterplot of the x vs y variable will be plotted and
the window argument will be ignored.
